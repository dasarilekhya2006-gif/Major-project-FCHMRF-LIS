**Document Title**: Implementation Specification for the Fully Connected Hidden Markov Random Field with Local Index of Significance (fcHMRF-LIS)  
**Project**: Adaptive Deep Learning-Assisted fcHMRF-LIS for Spatial False Discovery Rate Control in Neuroimaging

## 1. Scientific Objective

The primary objective of Phase 5 is to implement and validate the core **fcHMRF-LIS** statistical framework for spatial False Discovery Rate (FDR) control in neuroimaging. This document specifies the mathematical foundation, algorithmic procedures, parameter semantics, and software architecture, strictly demarcating the published baseline method from our research extensions.

### 2.1 Base Paper Method
- **Primary Reference**: Sun, W., & Cai, T. T. (2009). *Large-scale multiple testing under dependence*. Journal of the Royal Statistical Society: Series B (Statistical Methodology), 71(2), 393–424.
- **Dense Pairwise Inference Reference**: Krähenbühl, P., & Koltun, V. (2011). *Efficient inference in fully connected CRFs with Gaussian edge potentials*. Advances in Neural Information Processing Systems (NeurIPS 24).
- **Empirical Null Estimation**: Efron, B. (2004). *Large-scale simultaneous hypothesis testing: the choice of a null hypothesis*. Journal of the American Statistical Association, 99(465), 96–104.

Under the base paper method:
1. The prior probability of non-null activation is spatially uniform: $P(\theta_i = 1) = 1 - p_0$.
2. The Local Index of Significance (LIS) represents the conditional probability of the null hypothesis given the full spatial data: $\text{LIS}_i = P(\theta_i = 0 \mid \mathbf{Z})$.
3. In ranking hypotheses by LIS, Sun & Cai proved that the step-up procedure is optimal: it minimizes the False Non-Discovery Rate (FNDR) among all valid FDR-controlling procedures at nominal level $\alpha$.

### 2.2 Our Proposed Extensions
1. **Adaptive Spatial Prior Blending**: Instead of forcing a spatially flat prior $1 - p_0$, our extension incorporates anatomical and context-aware deep learning prior maps $\pi_i^{(\text{DL})} \in [0, 1]$ generated by the Phase 3 3D U-Net:
   $$P(\theta_i = 1) = \lambda_{\text{DL}} \pi_i^{(\text{DL})} + (1 - \lambda_{\text{DL}})(1 - p_0)$$
   where $\lambda_{\text{DL}} \in [0.0, 1.0]$ is a weighting hyperparameter.
2. **Strict Invariant Guarantee**: When $\lambda_{\text{DL}} = 0.0$ or when `method_mode = MethodMode.ORIGINAL_FCHMRF`, the model mathematically reduces to the exact base paper formulation.
3. **No Unjustified Novelty Claims**: The deep learning prior is treated as a testable scientific hypothesis, not an assumed superiority. Its contribution is benchmarked against the base paper method under identical data and noise configurations.

## 3. Mathematical Components

### 3.1 Inputs
1. **Statistical Test Statistics ($\mathbf{Z}$)**:
   - 1D vector of length $N$ or 3D volume $\mathbf{Z} \in \mathbb{R}^{X \times Y \times Z}$ representing voxel-level $z$-scores (derived from Phase 4 hypothesis testing or contrast estimation).
2. **Spatial Voxel Coordinates ($\mathbf{P}$)**:
   - Matrix $\mathbf{P} \in \mathbb{R}^{N \times 3}$ giving physical or grid coordinates $\mathbf{p}_i = (x_i, y_i, z_i)$ for all $N$ active voxels.
3. **Spatial Analysis Mask ($\mathbf{M}$)**:
   - Optional 3D boolean mask $\mathbf{M} \in \{0, 1\}^{X \times Y \times Z}$ restricting inference to brain parenchyma or specific anatomical regions.
4. **Coordinate Affine Matrix ($\mathbf{A}$)**:
   - $4 \times 4$ rigid/affine matrix mapping voxel indices to world scanner coordinates (RAS+ mm).
5. **Continuous Deep Learning Prior ($\boldsymbol{\pi}^{(\text{DL})}$)**:
   - Optional vector or 3D map $\boldsymbol{\pi}^{(\text{DL})} \in [0, 1]^N$ indicating voxel-wise prior activation probabilities from Phase 3.

### 3.3 Latent Variables
- Let $\theta_i \in \{0, 1\}$ denote the true, unobserved state of voxel $i$:
  $$\theta_i = \begin{cases} 0 & \text{voxel } i \text{ is inactive (null hypothesis } H_{0, i} \text{ holds)} \\ 1 & \text{voxel } i \text{ is active (alternative hypothesis } H_{1, i} \text{ holds)} \end{cases}$$
- Joint hidden configuration: $\boldsymbol{\theta} = (\theta_1, \dots, \theta_N)^T \in \{0, 1\}^N$.
- Marginal posterior probability under variational approximation:
  $$q_i(1) = Q(\theta_i = 1 \mid \mathbf{Z}) \in [0, 1]$$
  $$q_i(0) = Q(\theta_i = 0 \mid \mathbf{Z}) = 1 - q_i(1)$$

---

### 3.4 Estimation Procedure

#### 1. Emission Density Estimation (Two-Group Mixture via EM)
The marginal distribution of test statistics is modeled as a two-group Gaussian mixture:
$$f(z) = p_0 f_0(z) + (1 - p_0) f_1(z)$$
- **Null density**: $f_0(z) = \frac{1}{\sqrt{2\pi}\sigma_0} \exp\left( -\frac{(z - \mu_0)^2}{2\sigma_0^2} \right)$.
  When `fix_null = True`, $\mu_0 = 0.0$ and $\sigma_0 = 1.0$.
- **Active density**: $f_1(z) = \frac{1}{\sqrt{2\pi}\sigma_1} \exp\left( -\frac{(z - \mu_1)^2}{2\sigma_1^2} \right)$ with $\mu_1 > \mu_0$.
- Parameters $(p_0, \mu_1, \sigma_1)$ are estimated via Expectation-Maximization (EM) using central-quantile initialization to avoid non-identifiability.

#### 2. Unary Energy Computation
Under Gibbs representation $P(\boldsymbol{\theta} \mid \mathbf{Z}) \propto \exp(-E(\boldsymbol{\theta}))$, the unary potential $U_i(\theta_i)$ is:
$$U_i(0) = -\ln f_0(z_i) - \ln(1 - P(\theta_i = 1))$$
$$U_i(1) = -\ln f_1(z_i) - \ln(P(\theta_i = 1))$$

- **Base Paper Mode**:
  $$P(\theta_i = 1) = 1 - p_0$$
- **Adaptive DL Mode**:
  $$P(\theta_i = 1) = \lambda_{\text{DL}} \pi_i^{(\text{DL})} + (1 - \lambda_{\text{DL}})(1 - p_0)$$

---

### 3.5 Spatial Dependency Modeling

#### Fully Connected Bilateral Graph Kernel
Instead of truncating dependencies to immediate 6- or 26-connected nearest neighbors, the fcHMRF defines pairwise potential interactions between **all voxel pairs $(i, j)$**:
$$V_{ij}(\theta_i, \theta_j) = \beta \cdot K_{ij} \cdot \mathbf{1}(\theta_i \ne \theta_j)$$

where the dense affinity kernel $K_{ij}$ combines spatial proximity and radiometric consistency:
$$K_{ij} = w_1 \exp\left( -\frac{\|\mathbf{p}_i - \mathbf{p}_j\|^2}{2\sigma_s^2} - \frac{(z_i - z_j)^2}{2\sigma_r^2} \right) + w_2 \exp\left( -\frac{\|\mathbf{p}_i - \mathbf{p}_j\|^2}{2\sigma_{\text{pure}}^2} \right)$$
with diagonal self-interaction strictly excluded:
$$K_{ii} = 0 \quad \forall i \in \{1, \dots, N\}$$

#### Dense Message Passing & Memory Management
To compute all-to-all message propagation $\mathbf{m} = \mathbf{K} \mathbf{s}$ where $s_j = 2 q_j(1) - 1$:
1. For domains $N \le 8,000$ voxels, $\mathbf{K}$ is computed directly in memory.
2. For large whole-brain domains ($N > 8,000$), $\mathbf{K}$ is evaluated in contiguous row blocks of size $C$ ($C = 4,096$), achieving $O(N)$ working memory while strictly preserving dense, non-truncated pairwise connections.

---

### 3.6 Mean-Field Variational Inference

The intractable true posterior $P(\boldsymbol{\theta} \mid \mathbf{Z})$ is approximated by the mean-field product distribution:
$$Q(\boldsymbol{\theta}) = \prod_{i=1}^N q_i(\theta_i)$$

Minimizing the Kullback-Leibler divergence $\text{KL}(Q \parallel P)$ yields coordinate ascent updates for the log-odds ratio:
$$\ln \frac{q_i(1)}{q_i(0)} = U_i(0) - U_i(1) + 2\beta \sum_{j \ne i} K_{ij} (q_j(1) - 0.5)$$

Letting $\Delta_i = U_i(0) - U_i(1) + \beta \sum_{j \ne i} K_{ij} (2 q_j(1) - 1)$, the new unconstrained belief is:
$$q_i^{\text{new}}(1) = \sigma(\Delta_i) = \frac{1}{1 + \exp(-\Delta_i)}$$

To prevent limit cycles and ensure numerical stability, damped updates are applied:
$$q_i^{(t+1)}(1) = (1 - \tau) q_i^{(t)}(1) + \tau q_i^{\text{new}}(1)$$

Iterations continue until:
$$\max_{i \in \{1, \dots, N\}} |q_i^{(t+1)}(1) - q_i^{(t)}(1)| < \epsilon \quad \text{or} \quad t = T$$

---

### 3.7 Local Index of Significance (LIS) Calculation

Following Sun & Cai (2009), the Local Index of Significance is the posterior probability of the null state:
$$\text{LIS}_i = P(\theta_i = 0 \mid \mathbf{Z}) = 1 - q_i(1)$$
- Range: $\text{LIS}_i \in [0.0, 1.0]$.
- Interpretation: A low LIS indicates strong confidence that voxel $i$ is truly active given both its own statistical evidence and its neighborhood spatial consensus.

---

### 3.8 Step-Up Spatial FDR Controlling Procedure

To control the overall spatial False Discovery Rate at nominal level $\alpha$:
1. **Sort LIS values** in ascending order:
   $$\text{LIS}_{(1)} \le \text{LIS}_{(2)} \le \dots \le \text{LIS}_{(N)}$$
2. **Compute cumulative mean LIS**:
   $$\widehat{\text{FDR}}(j) = \frac{1}{j} \sum_{i=1}^j \text{LIS}_{(i)}$$
3. **Determine the step-up cutoff index**:
   $$k = \max \left\{ j \in \{1, \dots, N\} : \widehat{\text{FDR}}(j) \le \alpha \right\}$$
   If no such $j$ exists, $k = 0$ (no rejections).
4. **Decision Rule**:
   $$\text{Reject } H_{0, (i)} \quad \forall i \le k$$
   All voxels with $\text{LIS}_i \le \text{LIS}_{(k)}$ are declared statistically significant discoveries.

---

### 3.9 Outputs

The algorithm packages results into `FCHMRFResult`:
1. `lis_map`: 3D volume of LIS values in $[0, 1]$.
2. `lis_vector`: 1D array of active domain LIS values.
3. `significant_mask`: 3D binary mask of FDR-controlled discoveries.
4. `significant_vector`: 1D boolean discovery vector.
5. `posterior_prob`: 3D volume of posterior activation marginals $Q(\theta_i = 1)$.
6. `fdr_results`: Summary dictionary containing `nominal_alpha`, `estimated_fdr`, `num_discoveries`, and `lis_threshold`.
7. `model_parameters`: Summary dictionary of fitted mixture parameters and inference metrics.
8. `affine`: Preserved $4 \times 4$ spatial transformation matrix for exact NIfTI alignment.
9. `method_mode`: Execution mode label (`original_fchmrf` or `adaptive_dl_fchmrf`).

## 4. Verification and Validation Plan

1. **Analytical Unit Tests**:
   - Monotonicity of unary energies with respect to test statistics.
   - Symmetry and zero-diagonal properties of the dense bilateral kernel matrix.
   - Equivalence of blocked message passing to full matrix multiplication.
   - Strict reduction of adaptive DL mode to base paper mode when $\lambda_{\text{DL}} = 0.0$.
2. **Synthetic Spatial Ground Truth Benchmark**:
   - Synthesize a $16 \times 16 \times 8$ 3D spatial field with a known ground-truth spherical active cluster ($N_{\text{active}} \approx 137$ voxels, effect size $\delta = 3.5$, noise $\sigma = 1.0$).
   - Verify statistical sensitivity: True Positive Rate (TPR) $\ge 0.80$.
   - Verify FDR control: Empirical False Discovery Proportion (FDP) $\le \alpha + \text{tolerance}$.
3. **Reproducibility Guarantee**:
   - Preservation of geometric affine matrices on all exported NIfTI volumes.
   - Deterministic execution across fixed random seeds.

## 5. Scope Boundaries (What Phase 5 Does NOT Include)
- **NO Bayesian Optimization**: Bayesian hyperparameter tuning of $(\beta, \lambda_{\text{DL}})$ is deferred to Phase 6.
- **NO Sparse Graph Approximations**: All computations use dense bilateral modeling; no ad-hoc $k$-nearest-neighbor graph truncation is introduced.
